# NOL 公演助手（Chrome / Edge，Manifest V3）

v0.1.8 仅支持 NOL World 普通公演票，提供任务设置、官方时间倒计时、单次官方入场流程和可选的本机图片验证码辅助。登录、验证码提交、进入后的选场、选座、下单及付款由你完成。自动锁座、订单和支付尚未接入；完整状态与后续路线见仓库 [README](../README.md)。

开售时间只从官方接口读取，无需也不能手动设置。不设价格上限，但含费金额未知或币种不一致时订单校验仍不通过。公开价目不是最终含费金额。

## 安装与更新

ZIP 是源码分发包，先解压再加载，不是扩展商店的一键安装包。

1. 解压到固定目录，找到含 `manifest.json` 的 `extension` 文件夹。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展”，选中该文件夹。
4. 从工具栏打开扩展，点击“设置”。更新源码后在扩展管理页点击“重新加载”。

保留解压目录，移动或删除会影响扩展。请在排队前更新，不要为加载新代码刷新正在排队的官网页面。

v0.1.8 不再运行旧非普通票任务。这类任务保留供删除，不能保存或启动，更新后活动旧任务会停止。已有普通票任务继续兼容旧档位显示名，保存后规范为 `gradeLabel`；显示名不代替档位编号，旧人数字段不再保存。

## 设置与值守

1. 添加联系人：姓、名、邮箱、国家 / 地区电话代码及电话，姓名按证件填写。
2. 新建普通票任务，粘贴 `https://world.nol.com/{语言}/ticket/places/{placeCode}/products/{goodsCode}`。自动读取商品、公开票档和官方开售时间；失败时点击“重新读取”。
3. 选择普通开售或会员预售。只读显示北京时间与韩国时间；多个有效预售窗口必须选择对应类型。官网缺少有效起止时间或读取失败时不能保存 / 启动。
4. 填写张数、联系人及“购票优先顺序”。第一选择最想买，不可买时才考虑第二选择。每项设置演出日期、时间、票档和座区偏好；场次时间使用韩国时间 UTC+9，比北京时间快一小时。
5. 保存后开始值守，同一浏览器只运行一个任务。保持任务页前台、电脑清醒，同一账号只在一个浏览器运行。
6. 保存及启动时重新取官网时间，值守期间每分钟复核。官网延期开售时调整倒计时；接口失败、窗口消失或变化后已过时间时暂停。
7. 到时检查官网账号状态，沿正常 Turnstile 验证流程继续；出现挑战由你完成。通过后单次请求 `/api/users/enter/token` 并跳转官方 partner gate。登录 / 邮箱未完成、验证失败、响应不明或未知页面时人工接管。

过去的开售时间可以保存，但“开始值守”不会补触发；确需进入时使用“立即开始”。后台、休眠、浏览器重启或计时大跳后需重新检查，不静默补发。已领取的入场动作不会再次触发。

验证失败、取消或结果不明时，先检查官网，停止任务后再决定是否重新启动。已经成功提交入场接口时，“继续观察”只恢复观察，不重新请求入场。官方主页面连接超时或加载失败时提示接管，不自动重试，也不表示网络恢复；失败后 URL 已还原时可能漏报。

已适配的桌面繁中排队页可显示同一任务商品的顺位和等候人数。实际队列已确认时，入场回执不明确也可恢复观察，不篡改提交结果。保持现有标签，等待官网自动跳转；不要用“立即开始”重建队列。任务外手动打开的队列不能自动绑定，未知语言、商品或布局由你继续。

## 普通票选择规则

- 数量始终表示门票张数，受官网限购规则约束。
- 保存顺序先于价格；同一选择内先座区优先，再比较低价，允许分散座位的目标仍待真实选座适配。
- 非空的 `seatGrade`、`priceGrade` 必须分别匹配；不选票档时保留座区偏好。档位显示名仅作展示。
- 商品、场馆、日期、指定时间、档位、座区或张数不符合任务时，订单校验不通过。
- 不设价格上限，确认的高金额不会因价格排除；费用未知或币种不符仍需人工核对。

以上是配置与纯函数校验，尚未接到正式选座、锁座或 checkout。商品编号不是场次 ID，商品日期范围、预售编号及价格档编号也不能替代场次 / 座位 ID。

## 可选的本机验证码识别

1. 双击完整分发包 `local-ocr` 中的“安装本地识别.cmd”，完成后双击“启动本地识别.cmd”，保持服务窗口运行。首次安装需要联网下载依赖和模型，识别在本机运行。
2. 扩展弹窗点击“启用本机识别”，允许可选本机权限，再点击“检查服务”。未启用时不发送图片。
3. 正常进入已适配的选座页面，点击“识别当前图片”。只读取当前可见的 base64 图片，不请求官网验证码接口。
4. 对照图片核对、必要时修正六位字母，点击“核对并填入”。辅助框收起后，由你点击官网“完成输入”。填入不代表通过验证。
5. 图片刷新、弹层关闭或选座到期时丢弃旧候选。失败时手动处理，不自动刷新或循环尝试。弹窗可关闭识别并撤销本机权限，关闭服务窗口即可停服务。

目前只适配 JJ 普通票 26013793 / 26001167、2026-10-30 韩国时间 19:00 的已观察布局。仅接受已解码 PNG / JPEG / WebP base64 图片，网络图片不下载识别。可辅助手动进入的同一已验证页面，不绑定或重建队列，不处理 Turnstile。其他商品、场次及结构由你完成。

图片和候选临时经过扩展消息及 `127.0.0.1:8765`，不上传第三方 OCR，不保存到任务、联系人、诊断、文件或日志。真实 NOL 图片准确率与官网接受结果未验证，DOM 一致也不能保证图片仍有效。详见 [本机服务安装说明](../local-ocr/README.md)。

## 真实观察与未完成范围

2026-10-08，用户正常 Edge 会话中手动点击 JJ 普通票“先行订购”，同标签跳转 partner gate。最初连接超时，用户更换代理后正常排队，网站自动进入 `/onestop/schedule`。默认场次为 2026-10-30 韩国时间 19:00；点击官网“下一步”后进入 `/onestop/seat`，看到座区图、倒计时与图片验证码。验证码未完成，随后官网提示“10分钟的座位选择时间已超过”。

默认场次只记录当时页面状态，不是购买配置。此次没有选择或锁定座位，没有订单或付款；官网按钮与跳转观察也不能代替扩展入场 API 的真实账号验收。详见 [实际流程记录](docs/selection-and-hold.md)。

当前只读识别该目标选座页的商品、场次、地图、验证码和过期提示，不自动操作座位。静态图显示 FLOOR F1–F8、1F 102–105 / 110–114、2F 202–214、3F 308–314，部分座位可能受限；这不表示实时可售状态。[官方说明图](https://ticketimage.interpark.com/Play/ITM/Data/Modify/2026/9/2026092313042548.jpg)。

正式场次 ID、实时座位读取、足量选择、官方锁定 / 释放确认、资料填写、未支付订单、支付准备和付款均未完成。已从官方公开脚本定位预选和确认接口，但没有真实成功响应，也未启用后段请求。[OneStop 技术研究](docs/onestop-flow-research.md)。

## 本机数据与验证

任务和联系人保存在本机扩展存储，可单独删除或使用“删除全部本机数据”。Turnstile 验证及入场凭据只在官网页面流程中使用，不经过扩展消息、存储或诊断；可选 OCR 图片和候选临时经过消息与本机服务。`scripting` 用于当前 NOL 商品页正常同源入场流程，`webNavigation` 只识别三个已有官方域名中活动购票主页面错误，保存主机和固定错误码，不保存完整 URL 或凭据。[Chrome 权限说明](https://developer.chrome.com/docs/extensions/reference/api/webNavigation)。

v0.1.8 的 156 / 156 项 Node、19 / 19 项本机服务测试通过。Edge / Chrome 各 22 项普通票界面检查通过，包括旧任务禁用、不列入弹窗和单次模拟入场；各一次入场 POST，没有提前或重复触发。本机延迟 78 ms / 76 ms 不代表服务器耗时。另各 9 项弹窗状态及 6 项队列检查通过，这两类无入场、外发请求或应用控制台错误 / 警告。

实际 ddddocr 引擎在双浏览器各通过 10 项合成图检查：`ABCDEF` 识别为原始 `aBCdeF`，规范为 `ABCDEF`；覆盖人工修正 / 填入、图片刷新、隐藏旧层、过期及服务失败。官网提交为零，控制台无应用错误。权限仅在隔离 manifest 副本模拟授予；原生权限弹窗、真实 NOL 图片准确率和官网通过结果未验证。验证码页脚依据公开组件，尚未在新真实会话中重验。v0.1.7 的 151 项 Node 与假引擎检查仅为历史记录。
